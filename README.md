## 数据决定分支

- 每批一行参数与标量标签：表格回归，先比较均值、岭回归、树模型。
- 连续序列预测未来数值：时序预测，先朴素法、线性/DLinear，再比较更复杂模型。
- 一段过程序列预测终检标量：序列到标量回归，不能直接等同于未来序列预测。
- 图像与疵点标注：转入视觉任务分支，届时再补对应知识。

不要求先学完整CNN、手写完整GPT或跑遍所有模型。TSLib用于学习与基线参考，最新模型评估应结合官方代码与当前基准。
