# R02：机器学习入门选读

执行者：Codex带读＋本人复述；千问/Trae不默认接管阅读。状态与本人的实际理解以04-next及独立回报为准，本文不预填完成。

- 原文：[A Few Useful Things to Know about Machine Learning](https://homes.cs.washington.edu/~pedrod/papers/cacm12.pdf)；DOI：10.1145/2347736.2347755。
- 范围：PDF第2页三要素、第3—4页泛化段落；第4—5页过拟合可留下一轮。
- 一次最多30分钟；先做R01，再按余力选读。
- 做法：本人先看5分钟→指出一处疑问和自己的猜测→Codex给例子及定位→本人复述→Zotero记自己的解释。
- 验收：能举例区分模型、评价与优化；能解释为什么训练数据上的表现不能代替新数据评估。只验收选读内容。
- 未理解写“待解释”；AI导读、导入PDF不算本人读懂。没有实验不填指标，不将入门综述当成最新方法证据。
- 阅读队列独立于当前主代码任务；不抢占T01/C01认领。课程繁忙时顺延，不叠加工时。

两周试行预算与详细问题见[阅读入门](../../notes/reading-starter-20261021.md)。结束后新建独立回报，记录读到哪里、本人实际回答、仍不懂的点；本人未回答前保持待开始/进行中。
