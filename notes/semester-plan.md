# 本学期执行计划

更新：2026-10-20。当前版本替代此前固定阅读数量和预排大模型课程的安排。以下均为计划，实际成果以本人理解、运行记录和报告为准。

主线：任务澄清 → 数据审计 → 简单基线 → 可靠评估 → 一个有依据的研究问题。具体模型由输入输出与基线结果决定。

| 阶段 | 重点 | 验收 |
|---|---|---|
| 10-20—11-02 | 确认任务与反馈渠道；编程诊断；补齐D2L 2.2；英语诊断 | 一页任务卡、能解释的预处理练习 |
| 11-03—11-30 | 数据字典、划分、均值/线性/树基线、误差分析 | 2—4页baseline-v0报告与可复现入口 |
| 12月 | 英语与课程考核；保持已有实验；按需学习梯度和小型训练循环 | 英语错因记录；能复跑并解释实验 |
| 2027年1月 | 根据结果选一个后续假设；基础完成后再增加匹配模型 | 可复现项目、2—4份本人阅读笔记、一页继续/调整判断 |

## 任务卡

- 预测对象、输入、输出与实际使用时间。
- 数据来源、字段、标签、独立样本/批次/设备和权限。
- 划分依据、评价指标、最简单对照。
- 谁能反馈、目前已知困难、两周交付内容。
- 未知信息单列，不能假定数据或指导已落实。

## 学什么与为什么

| 内容 | 作用 | 掌握标准 |
|---|---|---|
| Python/pandas按需补 | 把原始记录变成正确样本 | 能解释缺失、编码、索引和字段时间 |
| NumPy、线性代数与回归 | 理解预测计算 | 说清输入、参数、输出形状 |
| scikit-learn、岭回归、一种树模型 | 建立值得信任的比较对象 | 相同划分下公平比较 |
| 分组/时间验证、误差分析 | 检查实际泛化与数据泄漏 | 解释评估对象、边界与失败例子 |
| PyTorch小型训练循环 | 理解学习参数的过程 | 能解释前向、损失、梯度与更新 |
| 数据结构与算法 | 维持计算机问题求解能力 | 独立修改解法并解释复杂度 |
| 英语 | 支撑考试、阅读、交流 | 分项练习与周期诊断 |

真实评估先划分数据，再在训练集拟合预处理。参见[官方实践说明](https://scikit-learn.org/stable/common_pitfalls.html)。

## 工作负荷

每周26小时试行：实验和配套数学12小时，英语7小时，计算机基础3小时，论文2小时，沟通复盘2小时。两周后依据实际完成量调整；课程作业、组内额外任务增加时同步缩减，不无限叠加。考试周减少模型扩展。

论文笔记围绕任务选择。DLinear仅为已有教学起点；不匹配真实任务时更换。固定精读篇数不优先于理解，AI导读不计为本人完成。

## 进阶条件

- 简单基线与评估没有完成，先不增加复杂模型。
- 只有任务匹配、基础就绪且指导条件明确时，才学习Attention或预训练模型。
- 2027上半年争取形成一个有反馈、可验证的研究问题；下半年争取完整实验和初稿，均非录用承诺。
- 公开数据练习与真实工业结论分开标注。实际研究必须符合所在项目的培养要求。
- 周末做一次短独立任务检验理解，允许查官方API；记录实际结果，不预填完成状态。
